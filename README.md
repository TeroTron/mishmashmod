# Red Alert 2: Romanov's Vengeance

Romanov's Vengeance is a 3rd party [OpenRA](http://www.openra.net) mod based on OpenRA [Red Alert 2](http://www.github.com/OpenRA/ra2) mod. It aims to create a Red Alert 2 style rts with a balanced multiplayer experience, alongside improvements that come from OpenRA and other features from more modern Command & Conquer games. A custom campaign is also being planned, but has not yet entered development.

Please note that mod is still under developement, the playtest versions are susceptible to bugs. There are still a few features from the original games that are missing, several instances of placeholder artwork, and content/balancing is always subject to change.

Installing the mod is done the same way as every other [OpenRAModSDK](http://www.github.com/OpenRA/OpenRAModSDK) mod.
